# Fandom Wikis and Web Scraping Homework

## Website Choice

For this assignment, I chose the Animal Jam Classic Wiki:
https://animaljam.fandom.com/wiki/Animal_Jam_Classic_Wiki

I chose this fandom because Animal Jam is a game I used to play when I was younger, so I have a personal connection to it. The wiki is a fan-created encyclopedia that documents different aspects of the game, including animals, items, and gameplay features.

## What I Scraped

I scraped the Animals category page:
https://animaljam.fandom.com/wiki/Category:Animals

From this page, I collected:
- animal_name
- animal_link

This page contains a structured list of playable animals in the game, which makes it suitable for web scraping and organizing into a dataset.

## Why This Data Is Useful

This data could be useful to researchers interested in:
- digital fandom communities and how they organize knowledge
- how players document and preserve information about games

## Ethics and Website Policies

Before scraping, I checked the website’s robots.txt file:
https://animaljam.fandom.com/robots.txt

The robots.txt file does not disallow access to standard wiki pages such as the Animals category page that I used. It mainly restricts access to special or administrative pages (such as /wiki/Special: and API endpoints). Therefore, scraping this public page is allowed.

I also reviewed the Fandom Terms of Use:
https://www.fandom.com/terms-of-use

For this assignment, I only collected a small amount of publicly available data for educational purposes, and I did not attempt to scrape restricted or sensitive content.
